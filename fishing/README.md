玩法
使用一般釣竿把浮標拋入水或岩漿，等待咬鉤後按右鍵開始收線，再依畫面完成連點進度條或指定點擊次數。每尾魚具有自己的重量、長度與稀有度。

活動由配套插件管理：預設每 60 分鐘開賽 5 分鐘，隨機抽選釣點及重量／長度／稀有度其中一項。每人取當場最佳單尾，同分先達成者優先。指定範圍內的常駐與活動漁獲均可計分；活動限定魚只在合格時間及場地出現。獎勵由伺服器管理員自行設定。
