# 拾光嶼整合材質包

供拾光嶼 Minecraft Java 26.3 玩家下載的伺服器材質包。

## 下載

請至 [Releases](https://github.com/llngh39690619-maker/shiguang-resource-pack/releases) 下載伺服器指定版本的 ZIP。

- 進服時允許「伺服器資源包」，由客戶端自動下載與套用。
- 手動安裝：將 ZIP 放入 Minecraft 的 `resourcepacks` 資料夾，不必解壓縮，再於「選項 → 資源包」啟用。
- 伺服器仍會驗證指定版本是否成功載入；手動安裝不會略過進服驗證。
- 更新時請以伺服器指定版本為準。每版 Release 提供檔案大小及 SHA-1／SHA-256 校驗值。
